# Monky Server

**Monky Server** é o painel gráfico para quem hospeda e prefere administrar sem terminal. Ele faz o mesmo papel do CLI, com interface gráfica.

Baixe pela [página de releases](https://github.com/MonkyOrg/Monky/releases). Os arquivos começam com `Monky-Server-`.

| Sistema | Arquivo |
|---|---|
| Windows | `Monky-Server-<versão>-win-x64-setup.exe` ou portátil |
| macOS | `Monky-Server-<versão>-mac-<arch>.dmg` |

## Telas

- **Dashboard** — estado do servidor, uso de disco e iniciar/parar.
- **Members** — membros cadastrados, cargos e permissões.
- **Settings** — nome do servidor, porta, limite de usuários e pasta de dados.
- **Logs** — saída do servidor em tempo real.

Para conversar, use o app Monky normal; Monky Server é para hospedar.
