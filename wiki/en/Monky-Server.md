# Monky Server

**Monky Server** is the graphical panel for hosts who prefer to administer without a terminal. It serves the same role as the CLI, with a GUI.

Download it from the [releases page](https://github.com/MonkyOrg/Monky/releases). Files start with `Monky-Server-`.

| System | File |
|---|---|
| Windows | `Monky-Server-<version>-win-x64-setup.exe` or portable |
| macOS | `Monky-Server-<version>-mac-<arch>.dmg` |

## Screens

- **Dashboard** — server state, disk usage and start/stop.
- **Members** — registered members, roles and permissions.
- **Settings** — server name, port, user limit and data directory.
- **Logs** — real-time server output.

To talk to friends, use the regular Monky app; Monky Server is for hosting.
